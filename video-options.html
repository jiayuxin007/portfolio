Round 02 · 清冷 / 极简 / 少元素

第二轮：更冷一点，更干净一点，东西再少一点

这次方向换了：不要繁密的星空星云，要「像一台钢琴」——黑白分明、留白很大、画面里只有一件事在缓慢发生。 下面 8 条按这个标准重筛。为了不靠观感瞎猜，我对每条视频都用 ffmpeg 抽了 3 帧做统计， 用数字来判断它到底「冷」还是「暖」、「空」还是「满」、「干净」还是「杂乱」。

  • 五个指标：L 平均亮度（越低越沉）· B−R 蓝减红（正数偏冷、负数偏暖）· sat 平均饱和度（越低越接近黑白）· bright% 亮部像素占比（越小说明留白越多、主体越小）· edge 边缘密度（越小画面越干净整洁）。
  • 怎么读：我想要的画面是「L 低 + B−R 不为负 + bright% 小 + edge 小」。按这个组合，16、17、18 三条最像钢琴：一个主体，一大片黑。
  • 不追星云了：这一轮刻意把「星云」全部剔掉。剩下的星星要么是稀疏颗粒（19），要么干脆没有（20、21），主要靠黑、灰、月光说话。
  • 偏暖也能救：17 号实测略偏暖（B−R = −10），一条 CSS 滤镜就能压成冷调，代码放在表格下面。

把任何一条压成「清冷」的 CSS
素材只是底子，冷调最终是调出来的。直接给首页背景层加滤镜即可，不需要重新导出视频： 
/* 通用：降饱和、压亮部、提一点对比 —— 画面立刻变冷变干净 */
.video-layer video {
  filter: saturate(0.62) brightness(0.88) contrast(1.06);
}

/* 针对偏暖的画面（例如 17 号满月）：再往蓝偏一点点 */
.video-layer video.is-warm {
  filter: saturate(0.7) hue-rotate(-6deg) brightness(0.9) contrast(1.05);
}
注意：滤镜是叠在解码后的画面上算的，几乎不增加开销；但别把 brightness 压过 0.8，否则暗部会糊成一片死黑。

第二轮那五项色彩数据不是估的：用 ffmpeg 在每条视频的 15%、50%、85% 处各抽 1 帧， 缩放到 32×18 像素后统计平均 RGB、亮度、饱和度、亮部占比和相邻像素亮度差，三帧取平均。 「冷」看 B−R，「空」看 bright%，「干净」看 edge —— 所以筛掉的那些（比如 19007、45600）不是不好看，是数字上太满太闹。
